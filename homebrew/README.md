# Саморобні матеріали (Homebrew)

Ця папка збирає авторський контент, який доповнює офіційний модуль *Dragon of Icespire Peak*, але не є його частиною: розширені передісторії NPC, документи та предмети-хендаути для гравців, альтернативні гачки сюжету тощо.

Кожна тема живе у власній підпапці, названій за локацією або персонажем, якого вона стосується.

## Зміст

- [`Axeholm/`](Axeholm/backstory.md) — квест Axeholm: передісторія банші Вілдари, три хендаути, з яких гравці можуть дізнатися її історію, і NPC-зачіп у Фандаліні.
